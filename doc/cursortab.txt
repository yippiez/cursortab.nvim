INTRODUCTION                                           *cursortab-introduction*

cursortab.nvim is the visual layer for edit completions and cursor
predictions: ghost text, inline diff overlays (additions, deletions,
modifications), and a cursor-jump ("TAB") indicator.

The bundled Go completion server has been removed. This plugin now ships only
the rendering layer and the editor-side glue (keymaps and autocommands). Bring
your own backend: compute a diff, call |cursortab.show_completion|, and the
plugin draws it. See |cursortab-backend|.

It is pure Lua with no build step and no external processes.

==============================================================================
SETUP                                                         *cursortab-setup*

Using lazy.nvim: >lua

  {
    "cursortab/cursortab.nvim",
    event = "VeryLazy",
    config = function()
      require("cursortab").setup({
        -- your config here
      })
    end,
  }
<

==============================================================================
CONFIGURATION                                                *cursortab-config*

Full configuration with defaults: >lua

  require("cursortab").setup({
    enabled = true,

    keymaps = {
      accept = "<Tab>",           -- Accept completion, or false to disable
      partial_accept = "<S-Tab>", -- Partially accept, or false to disable
      trigger = false,            -- Manual trigger key, or false to disable
    },

    ui = {
      completions = {
        addition_style = "dimmed", -- "dimmed" or "highlight"
        fg_opacity = 0.6,          -- 0=invisible, 1=fully visible
      },
      jump = {
        symbol = "",
        text = " TAB ",
        show_distance = true,
      },
    },

    blink = {
      enabled = false,
      ghost_text = true,
    },
  })
<

Unknown keys are rejected at setup() time.

KEYMAP OPTIONS                                       *cursortab-config-keymap*

keymaps.accept                                  *cursortab-config-keymaps-accept*

  The keymap to accept the visible completion/prediction in insert/normal
  mode. A keymap string (e.g., "<Tab>") or `false` to disable. Default:
  "<Tab>". Set to `false` when managing the accept keymap yourself.

keymaps.partial_accept                  *cursortab-config-keymaps-partial-accept*

  The keymap to partially accept a completion. A keymap string (e.g.,
  "<S-Tab>") or `false`. Default: "<S-Tab>".

keymaps.trigger                              *cursortab-config-keymaps-trigger*

  The keymap to invoke the `trigger` handler manually. A keymap string
  (e.g., "<C-Space>") or `false`. Default: false.

UI OPTIONS                                                *cursortab-config-ui*

ui.completions                            *cursortab-config-ui-completions*

  `addition_style` Rendering style for addition groups (default: "dimmed").
                  "dimmed"    - Dimmed treesitter-highlighted overlay.
                  "highlight" - Classic green background highlight.

  `fg_opacity`     Opacity for completion overlays (default: 0.6).
                  0 = invisible, 1 = fully visible.

ui.jump                                              *cursortab-config-ui-jump*

  `symbol`        Symbol shown before jump indicator (default: "").
  `text`          Text shown in jump indicator (default: " TAB ").
  `show_distance` Show line distance for off-screen jumps (default: true).

BLINK OPTIONS                                            *cursortab-config-blink*

  `blink.enabled`
      Expose append-char ghost text as a blink.cmp source (default: false).

  `blink.ghost_text`
      Render inline ghost text for appended characters (default: true).

HIGHLIGHT GROUPS                                       *cursortab-highlights*

All highlight groups are defined with `default = true`, so they can be
overridden by your colorscheme or by calling `nvim_set_hl` before or after
`setup()`.

CursorTabDeletion                                        *hl-CursorTabDeletion*
    Background highlight for deleted text.
    Default: `ctermbg=DarkRed bg=#4f2f2f`

CursorTabAddition                                        *hl-CursorTabAddition*
    Background highlight for added text.
    Default: `ctermbg=DarkGreen bg=#394f2f`

CursorTabModification                                *hl-CursorTabModification*
    Background highlight for modified text shown beside the original.
    Default: `ctermbg=DarkGray bg=#282e38`

CursorTabCompletion                                    *hl-CursorTabCompletion*
    Foreground color for inline completion ghost text.
    Default: `ctermfg=DarkBlue fg=#80899c`

CursorTabJumpSymbol                                    *hl-CursorTabJumpSymbol*
    Foreground color for the jump indicator symbol.
    Default: `ctermfg=Cyan fg=#373b45`

CursorTabJumpText                                        *hl-CursorTabJumpText*
    Colors for the jump indicator text label.
    Default: `ctermbg=Cyan ctermfg=Black bg=#373b45 fg=#bac1d1`

Example override: >lua
    vim.api.nvim_set_hl(0, "CursorTabAddition", { bg = "#1a3a1a" })
<

RENDERING API                                              *cursortab-render*

                                                    *cursortab.show_completion*
require("cursortab").show_completion({diff_result})

  Render a completion diff. {diff_result} is a table with a `groups` array;
  each group targets a 1-indexed `buffer_line` and describes how to draw it.

  A group has:
    type          "modification" | "addition" | "deletion"
    start_line    1-indexed, relative to the diff content
    end_line      1-indexed, inclusive
    buffer_line   1-indexed absolute buffer position for rendering
    lines         string[]  new content
    old_lines     string[]  existing content (modifications)
    render_hint   "append_chars" | "replace_chars" | "delete_chars" |
                  "stacked" | nil
    col_start     byte offset for character-level hints
    col_end       byte offset for character-level hints

                                             *cursortab.show_cursor_prediction*
require("cursortab").show_cursor_prediction({line_num})

  Render the cursor-jump ("TAB") indicator at {line_num} (1-indexed). If the
  line is off-screen, a directional indicator is shown at the viewport edge.

                                                              *cursortab.clear*
require("cursortab").clear()

  Clear all visuals (ghost text, overlays, jump indicator).

==============================================================================
WIRING A BACKEND                                           *cursortab-backend*

The plugin owns the keymaps and autocommands; a backend reacts by overriding
handlers in `require("cursortab").handlers` and rendering with the API above.
All handlers default to no-ops. >lua

  local cursortab = require("cursortab")

  cursortab.handlers.event = function(name)
    -- name: "text_changed" | "cursor_moved" | "insert_enter"
    --     | "insert_leave" | "file_saved"
    -- Request a completion, then render it:
    --   cursortab.show_completion(diff)
    --   cursortab.show_cursor_prediction(line)
  end

  cursortab.handlers.accept = function() end          -- Tab on a visible completion
  cursortab.handlers.partial_accept = function() end  -- partial-accept key
  cursortab.handlers.trigger = function() end         -- manual trigger key
  cursortab.handlers.reject = function() end          -- visuals dismissed
<

The visual layer clears itself on cursor movement or non-matching edits, so
backends only need to render.

COMMANDS                                                   *cursortab-commands*

:CursortabToggle                                            *:CursortabToggle*
    Toggle the visual layer on/off.

:CursortabDemo                                                *:CursortabDemo*
    Render a sample ghost-text completion on the current line so the visuals
    can be inspected without a backend.
